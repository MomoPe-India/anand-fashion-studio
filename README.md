## 1. Zero-Cost Hosting Guide (₹0 / Month Forever)

This website is built with lightweight, modern static architecture (HTML5, Tailwind CSS, Vanilla JavaScript, Native Dialogs). It does not require any database or PHP server, meaning **hosting is 100% FREE forever**.

### Option A: Cloudflare Pages (Recommended - Fastest in India)
1. Sign up for free at [pages.cloudflare.com](https://pages.cloudflare.com).
2. Go to **Workers & Pages** → **Create application** → **Pages** → **Upload assets**.
3. Drag & drop this entire project folder (`index.html`, `styles.css`, `script.js`, `robots.txt`, `sitemap.xml`).
4. Instant live URL: `anandfashionstudio.pages.dev` (Cost: **₹0**).
5. Add custom domain (e.g. `www.anandfashionstudio.in`) under **Custom Domains** tab with 1-click free SSL.

### Option B: Vercel
1. Install Vercel CLI (`npm i -g vercel`) or upload to GitHub.
2. Run `npx vercel deploy` or import repo in Vercel dashboard.
3. Cost: **₹0 / forever**.

### Option C: GitHub Pages
1. Push repository to GitHub.
2. In repo **Settings** → **Pages** → select `main` branch root.
3. URL: `username.github.io/anand-fashion-studio`.
